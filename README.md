## 🧭 À propos

Architecte logiciel et manager avec plus de 20 ans d'expérience dans la conception de plateformes bancaires et l'encadrement d'équipes techniques. Actuellement **Team & Account Manager / Principal Project Manager chez Finastra**, où je pilote une équipe de 12 consultants sur des projets de core banking (Ktp PaymentFactory, eConnect), de l'avant-vente à la mise en production.

Depuis 2024, je poursuis en parallèle un **Executive Master en Intelligence Artificielle & Data Science à l'Université Paris-Dauphine | PSL (EMIASD)**, pour élargir mon expertise historique (Java/Spring, architectures distribuées) vers le Machine Learning, le Deep Learning et la Data Science.

Ce compte GitHub rassemble les travaux réalisés dans le cadre de cette formation.
